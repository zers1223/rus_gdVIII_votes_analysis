Репозиторий содержит несколько html файлов, представляющих собой результат небольшого анализа голосований депутатов Государственной Думы РФ VIII созыва. 
При построении диаграммы были обработаны результаты голосований по **16 689 вопросам** для **479 депутатов**.
Депутаты, у которых более 10% пропусков не были учтены при анализе.

Первое обработанное голосование: 2021-10-12 10:28:17  
Последнее учитанное голосование: 2026-07-27 10:11:03  
Все данные были получены при помощи api с официального сайта госдумы **[http://api.duma.gov.ru](http://api.duma.gov.ru)**

### Интерактивная карта проекта

Расстояние между двумя точками представляет собой схожесть по всем голосованиям. Чем ближе точки друг к другу, тем более похожи голосования.

Данные в виде excel файла: **[https://docs.google.com/spreadsheets/d/1e7P1CsN6ibwy9UqRtqdFxnY9JEnNk_Wt](https://docs.google.com/spreadsheets/d/1e7P1CsN6ibwy9UqRtqdFxnY9JEnNk_Wt)**

## Как обрабатывались данные
1) По каждому голосованию депутату присваиволось значение исходя из его решения:  
- За: +1  
- Против: -1  
- Воздержался: 0  
- Не голосовал: 0  
- Не был депутатом: 0  

2) Затем используя полученную матрицу 16689 x 479
вычислялось попарное **Косинусное сходство (Cosine Similarity)** между векторами голосования всех депутатов.  
3) Для снижения размерности было использовано метрическое многомерное шкалирование (Metric MDS).  
Алгоритм должен был сохранить исходные расстояния между объектами
