Репозиторий содержит один html файл, представляющий собой результат небольшого анализа голосований депутатов Государственной Думы РФ VIII созыва. 
Были обработаны результаты голосований по **16 689 вопросам** для **479 депутатов**.
Первое обработанное голосование: 2021-10-12 10:28:17
Последнее учитанное голосование: 2026-07-27 10:11:03
Все данные были получены при помощи api с официального сайта госдумы **[http://api.duma.gov.ru](http://api.duma.gov.ru)**
